# 📦 DAAM (Durable Articles Asset Management System)
### ระบบบริหารจัดการครุภัณฑ์ พร้อมฟังก์ชันสแกน QR Code ยืม-คืน และนำเข้าข้อมูล CSV

---

## 📌 ภาพรวมโครงการ (Project Overview)
**DAAM** เป็นเว็บแอปพลิเคชันสำหรับบริหารจัดการครุภัณฑ์ การตรวจนับ การยืม-คืน และการติดตามสถานะครุภัณฑ์ภายในหน่วยงานหรือองค์กร พัฒนาด้วยภาษา **PHP Native (PDO)** เพื่อความปลอดภัย ยืดหยุ่น และง่ายต่อการปรับปรุงบำรุงรักษา

### 🌟 ฟีเจอร์เด่นของระบบ (Key Features)
1. **ระบบฐานข้อมูลแบบ 2 สภาพแวดล้อม (Dual Database Architecture):**
   - **Development:** ใช้ **SQLite** (`control/daam_dev.sqlite`) แบบ Serverless รันและทดสอบได้ทันทีบนเครื่อง ไม่ต้องพึ่งพา MySQL Server ภายนอก
   - **Production:** รองรับ **MySQL / MariaDB** ผ่าน PDO พร้อมสคริปต์ถ่ายโอนข้อมูล (`migrate_data.php`)
2. **ระบบสแกน QR Code ยืม-คืนอัจฉริยะ (Smart 2-in-1 QR Code):**
   - URL เดียวกันรองรับทั้งการ **"ยืม"** และ **"คืน"** (`user/borrow_action.php?da_id=...`)
   - ออกแบบ UI แบบ **Mobile-First** สำหรับหน้าจอมือถือ ปุ่มใหญ่ ใช้งานสะดวก
   - ระบบ **Session Redirection**: หากยังไม่ล็อกอิน ระบบจะจำหน้าไว้ เมื่อล็อกอินสำเร็จจะนำทางกลับมาทำรายการต่อทันที
   - แอดมินสามารถสั่งพิมพ์ป้าย QR Code สติ๊กเกอร์แปะประจำเครื่องได้ทันที (`admin/print_qr.php`)
3. **ระบบนำเข้าข้อมูลครุภัณฑ์ผ่าน CSV (Bulk Import with Auto-Classification):**
   - รองรับการนำเข้าไฟล์ `.csv` แบบชุดข้อมูลขนาดใหญ่
   - ตรวจสอบความซ้ำซ้อน: ถ้ามีรหัสเดิมจะทำการ **Update**, ถ้าไม่มีจะทำการ **Insert**
   - **Smart Classification Auto-Detection:** ตรวจจับและกำหนดหมวดหมู่ครุภัณฑ์ (`classificationID`) ให้อัตโนมัติจากโครงสร้างรหัสครุภัณฑ์ หรือคีย์เวิร์ดชื่อรายการ แม้ผู้ใช้จะเว้นว่างไว้
4. **ระบบจัดการข้อมูลสำหรับผู้ดูแลระบบ (Admin Panel):**
   - สรุปสถิติภาพรวมใน Dashboard
   - จัดการครุภัณฑ์ และจัดการบัญชีผู้ใช้งาน (เพิ่ม/แก้ไข/ระงับ/รีเซ็ตรหัสผ่าน)
5. **ระบบติดตามสำหรับผู้ใช้งานทั่วไป (User Dashboard):**
   - แสดงสถิติการยืมส่วนบุคคล และการแจ้งเตือนครุภัณฑ์ที่เลยกำหนดคืน (Overdue)
   - ตารางค้นหาและกรองรายการตามหมวดหมู่ (Category Filter Dropdown)

   ```
   http://localhost:8000
   ```

## 🗄️ รูปแบบข้อมูลสำหรับการนำเข้า CSV (CSV Import Specification)

ไฟล์ CSV ต้องบันทึกด้วยการเข้ารหัส **UTF-8** โดยมีหัวคอลัมน์ 7 คอลัมน์ดังนี้:

| ลำดับ | ชื่อคอลัมน์ | คำอธิบาย | ตัวอย่าง | ข้อกำหนด |
| :---: | :--- | :--- | :--- | :--- |
| 1 | `DA_Number` | รหัสครุภัณฑ์ | `1206-001` | จำเป็นต้องระบุ (ใช้เป็น Primary Reference) |
| 2 | `DA_ListName` | ชื่อรายการครุภัณฑ์ | `คอมพิวเตอร์โน้ตบุ๊ก` | จำเป็นต้องระบุ |
| 3 | `DA_Brand` | ยี่ห้อ | `ASUS` | เว้นว่างได้ |
| 4 | `classificationID` | รหัสหมวดหมู่ | `c0000000004` | **เว้นว่างได้** (ระบบตรวจจับให้อัตโนมัติ) |
| 5 | `buildingID` | รหัสอาคาร | `ACB` | ควรระบุให้ตรงกับตาราง building |
| 6 | `classroomID` | รหัสห้อง | `CLB3100` | ควรระบุให้ตรงกับตาราง building_classroom |
| 7 | `DA_Price` | ราคาครุภัณฑ์ | `25000.00` | ตัวเลข (ใส่หรือตัดจุลภาคได้) |

> 💡 **หมายเหตุ:** รายการนำเข้าใหม่จะได้รับสถานะ **`s0001` (พร้อมใช้งาน)** ให้อัตโนมัติ

## 🔒 ความปลอดภัย (Security Practices)
- ใช้งาน **PDO Prepared Statements** ในทุกคำสั่ง SQL เพื่อป้องกัน **SQL Injection**
- เข้ารหัสรหัสผ่านด้วยอัลกอริทึมมาตรฐานสากล `password_hash()` และตรวจสอบด้วย `password_verify()`
- มีการตรวจสอบสิทธิ์การเข้าถึง (Role-Based Access Control) ในทุกหน้า ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต
- บันทึกข้อมูลแบบ **Database Transactions** กรณีนำเข้าข้อมูลเป็นชุดหรือทำรายการยืม-คืน เพื่อความสมบูรณ์ของฐานข้อมูล (ACID)
